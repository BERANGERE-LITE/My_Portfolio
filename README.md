# My Professional Portfolio

A responsive personal portfolio website built to showcase my software engineering background, technical skills, projects, and professional experience.

## Features
- **Responsive Design:** Optimized for both mobile devices and desktop screens.
- **Interactive Sections:** Home, About, Skills, Experience & Projects, and Contact form.
- **Modern UI:** Built with a clean dark theme using HTML5, CSS3, and JavaScript.

## Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (ES6)
